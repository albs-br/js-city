# JS City

A playful little SimCity-inspired experiment built in plain JavaScript, designed as a small "vibe-coding" sandbox for city-building ideas, toy economics, and retro browser game energy.

This project started as a fun coding experiment: sketch a compact city simulation, keep the rules simple, and make something satisfying to click around in a browser.

## 🌆 What is this?

JS City is a lightweight urban builder where you:

- place roads, homes, shops, industry, and parks
- manage a tiny economy with limited funds
- grow a small population over time
- watch your city evolve month by month
- experiment with layout and balance

It is intentionally simple, charming, and a bit chaotic in the best way.

## 🎮 How to play

1. Open the project in a browser.
2. Choose a tool from the side panel.
3. Click tiles on the map to place roads and zones.
4. Build enough housing and infrastructure to attract residents.
5. Advance time and watch your city grow.

## 🧩 Features

- Grid-based city building
- Road connectivity logic
- Residential, commercial, and industrial zoning
- Park placement and bulldozer cleanup
- Resource balancing and monthly growth simulation
- Minimal UI with a retro game aesthetic

## 🚀 Run it locally

Because this is a simple browser game, you can run it with any local static server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Use a local server

From the project folder, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
